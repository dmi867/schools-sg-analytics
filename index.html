Портфель — 48 капремонтов школ. Ниже — риск по деньгам, а не по проценту готовности: пять правил и решения, которые из них следуют. У каждого правила — цифры конкретно по этому портфелю, без общих слов.

1. Судить объект по отклонению от нормы для его этапа, не по проценту оплаты

Разрыв между готовностью и оплатой растёт по ходу стройки у всех объектов одинаково закономерно: на старте аванс идёт впереди работ, после экспертизы оплата по актам отстаёт. Это норма, а не проблема сама по себе. Проблема — когда конкретный объект отклоняется от этой нормы. На графике две кривые разрыва СГ−выплаты: сплошная — медиана по школам (каждая школа = один голос), пунктир — взвешенная по объёму контракта (типичный рубль портфеля).

2. Красная зона: школ отклоняются сильнее порога своего этапа

Порог считается отдельно на каждом этапе готовности: max(8, 0,75×IQR разрывов). На этапе ~90% норма разрыва — около п.п. Школы в таблице отклоняются от нормы сильнее порога этапа. Пометка «типовой аванс» — % выплат застрял около размера аванса, это не прогресс по актам.

Ни одного платежа по актам, только аванс — при этом часть объектов готова на 95–100%. Добавлять финансирование таким объектам бессмысленно: деньги не идут не из-за нехватки бюджета, а потому что акты о выполненных работах не доходят до оплаты. Разбираться нужно в процедуре приёмки — у заказчика или у подрядчика, а не в объёме транша.

7. У школ экспертиза не пройдена — вот куда смотреть, почему стоят деньги

Появился источник, которого не было раньше (выгрузка ПИР): по каждой заявке на экспертизу видно её реальный результат и историю. У части школ последнее полученное заключение — «Отрицательное», у части заявка ещё открыта («в экспертизе» — замечания, рассмотрение ПД и т.п., итогового заключения нет). Больше половины этих школ уже были в красной зоне или списке нулевого освоения выше — это, похоже, и есть причина, а не совпадение.

Данных нет

Условия контрактов — ставки пеней, размер банковских гарантий, пороги расторжения. Без этого раздел про рычаги на подрядчика (принцип 5) остаётся на уровне общих принципов, а не конкретных цифр давления по каждому договору.

Выводы и что делать
  • На этой неделе: эскалировать все школ с нулевым освоением — по каждой получить причину (акты не поданы / спор / организационная задержка у заказчика) и решение: ускорить или честно перенести бюджет на 2027 год.
  • На этой неделе: запросить статус актов по школам в красной зоне — они отстают от нормы для своего этапа больше, чем объясняет обычный цикл оплаты.
  • В течение месяца: разбор на уровне договора с подрядчиками, у которых зависли все объекты без исключения (раздел 5 выше) — точечные меры по одной школе тут не сработают.
  • Не выделять новый аванс школам, которые уже сидят только на авансе (раздел 4) — вместо этого требовать акты. Дополнительные деньги не решают проблему с документами.
  • Использовать эталонную кривую (раздел 1) как чек-лист перед каждым траншем: этап готовности объекта сверять с нормой, а не только со сроком по контракту.
Чего не хватает для более точного анализа
  • Причина теперь видна не для всех: у части школ из красной зоны и нулевого списка нашлась конкретная причина — отклонённая экспертиза (раздел 7). Но не для всех — у оставшихся причину (акты не поданы / спор / организационная пробуксовка) всё ещё предстоит выяснить у заказчика и подрядчика напрямую.
  • Нет истории по годам: неизвестно, типична ли пробуксовка в начале года — возможно, часть объектов обычно нагоняет в четвёртом квартале, и тогда часть «красной зоны» — не риск, а сезонность.
  • Нет данных об условиях контрактов (штрафы, порядок расторжения) — непонятно, какие реальные рычаги есть на переговорах с проблемными подрядчиками.
  • Список подрядчиков и бюджет 2026 года сверены вручную один раз по состоянию на начало сентября — при обновлении отчёта их нужно сверять заново, автоматически это не пересчитывается.
  • Порог красной зоны — свой на каждый этап (0,75×IQR, не меньше 8 п.п.), а не фиксированные 15 п.п. Эталонная кривая дублируется с весом по контракту. Объекты с «круглым» % выплат около типового аванса помечены отдельно.
Как считается красная зона и эталон
Сделано

Порог по этапу. Для каждого этапа готовности берём разброс разрывов СГ−выплаты (IQR) и ставим порог max(8, 0,75×IQR). Красная зона — отклонение от медианы этапа выше этого порога.

Сделано

Вторая эталонная кривая. Рядом с медианой «по школам» — взвешенная медиана по объёму контракта («типичный рубль портфеля»).

Сделано

Флаг «типовой аванс». % выплат в полосе 26,5–27,5% или совпадение с долей аванса при нулевых платежах по актам. На дашборде — отдельный фильтр.
